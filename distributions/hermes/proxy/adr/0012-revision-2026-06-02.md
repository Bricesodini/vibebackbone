# ADR 0012 — Révision du 2026-06-02 : Harmonisation D1-D7

**Status**: PROPOSED
**Date**: 2026-06-02
**Route**: STRUCTURED
**Décideurs**: Brice Sodini (validation), Hermes (orchestration), vbb-struct-worker (exécution des patches)
**Chantier**: Proxy de confidentialité

## Contexte

Brice a validé le 2026-06-02 un ensemble de décisions architecturales (D1-D7) et de règles opérationnelles (5-7) qui n'étaient pas toutes présentes dans les ADRs fondateurs 0006-0010. Une révision ciblée par patches a été appliquée pour harmoniser l'ensemble.

## Décisions intégrées

| ID | Décision | ADRs impactées |
|----|----------|----------------|
| **D1** | Proxy = un seul process Python au POC, avec séparation interne claire (profil logique + daemon local) | 0006 |
| **D2** | Interface POC = HTTP localhost + HMAC ; queue file-based devient un fallback futur | 0006 |
| **D3** | Chiffrement = libsodium SecretStream (XChaCha20-Poly1305) prioritaire, AES-256-GCM en fallback documenté | 0007, 0010 |
| **D4** | Identité unique du proxy au POC (single process), split en V2 si besoin | 0006 |
| **D5** | Concurrence = mutex par credential/target, FIFO par target sensible, refus ou attente explicite en cas de lock | 0007, 0008, 0009 |
| **D6** | Rate-limiting POC = 30 req/min/appelant, 5 actions sensibles/h, 10 simultanées max, HTTP 429 + Retry-After + audit + Telegram | 0008, 0009, 0010 |
| **D7** | Repo governance rule = aucun worker n'appelle ssh/scp/rsync/gh auth/docker login/cat .env/printenv secrets. Linter vbb-bypass-lint.py en V2, revue manuelle au POC. Référence : ADR 0011. | 0009, 0010, 0011 |

## Extensions du contrat d'interface

Le contrat JSON du proxy (cf. ADR 0006 §2.6.1) a été étendu avec :

- `contract_version` (string semver, obligatoire, ex: "1.0.0")
- `request_id` (ULID ou UUIDv7, généré par l'appelant, obligatoire)
- Convention `snake_case` stricte (refus si camelCase ou kebab-case)
- Limite params : 4 KB par défaut, 64 KB maximum absolu
- Params longs/sensibles : fichier temporaire référencé par hash SHA-256, dans `~/.hermes/proxy/scratch/<request_id>.bin`, chiffré, purgé après 1h

- L'ensemble des 6 ADRs (0006-0011) est désormais **cohérent sur D1-D7** et **cross-référencé**
