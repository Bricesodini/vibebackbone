# distributions/claude/ — Claude Code distribution

The currently active distribution of VBB Core for the Claude Code agent
runtime. **ACTIVE** as of ADR 0013 Phase 4 (2026-06-13).

## What lives here (migrated in ADR 0013 Phase 4)

- `CLAUDE.md` (← was `CLAUDE.md` at root, tracked `git mv`; root is now
  a relative symlink → `distributions/claude/CLAUDE.md`).

## Future content (not yet migrated)

- Claude Code-specific adapters
- Claude Code-specific skills
- Claude Code-specific prompts

## What does NOT belong here

- `~/.claude/` (user-side Claude Code home — runtime, generated by Claude
  Code itself).
- `.claude/settings.local.json` (KEEP ROOT — Claude Code runtime generates
  it on first launch; it is per-machine, gitignored, and must remain at
  the repo root for the runtime to find it).
- `.claude/` directory at the repo root — runtime-owned, untouched by
  Phase 4.

## Status

Active. 1 file lives here (CLAUDE.md) + 1 symlink at the root preserves
Claude Code's `@import` compatibility. `.claude/` (runtime) stays at root.
