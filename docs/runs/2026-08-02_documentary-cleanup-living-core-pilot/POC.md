# POC — Living core documentary cleanup pilot

## Hypothesis

The aligned documentary skills can inspect a bounded living-core surface,
produce independent C0-C5 findings and route each finding through Critical
Rule 16 without silently changing an artefact.

## Success criteria

- every examined artefact has an observed identity or `UNKNOWN`;
- authority, representation, projection, evidence and compatibility remain
  distinct;
- each drift is recorded as a finding with evidence and confidence;
- no artefact is modified before an explicit human response;
- `UNKNOWN` findings are not treated as proof of independence or as an
  automatic remediation route.

## Stop criteria

Stop before classification or remediation if the scope expands, the authority
cannot be established, or a route would require a canon change not explicitly
decided by a human.

## Decision

Décision: GO for bounded observation and finding production only. The run must
obtain human decisions before any remediation route is considered.
