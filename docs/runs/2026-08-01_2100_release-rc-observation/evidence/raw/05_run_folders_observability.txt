# OBSERVATION KEY — Run folders traceability in main

## Découverte
Les dossiers de run pour le cycle rc.2 (2026-08-01_*) **ne sont
pas dans origin/main** après le merge `b4bedbb`.

Investigation:
- `git diff --name-only 6b0daf4 b4bedbb` retourne 92 fichiers
- **Aucun** de ces fichiers n'est sous `docs/runs/2026-08-01_*`
- La comparaison `git ls-tree -r origin/main docs/runs/ | grep 2026-08-01` retourne 0

## Cause
Le merge `b4bedbb` (parents=[6b0daf4, b5e2828]) n'a inclus que:
- Le commit candidat `3486300` (chore(release): prepare v1.1.0-rc.2 candidate)
- Le commit intégration `b5e2828` (docs(runs): remediate external pilot)

Les 17 commits antérieurs du branch étaient des commits déjà présents
sur d'autres branches (bd8f3fa, c11f5c1, ..., 0d4d683). Les dossiers
runs 2026-08-01_* ont été créés sur le filesystem mais **jamais
committés** à la branche.

## Récupérabilité
Les fichiers sont **préservés dans le stash** `stash@{0}` :
```
$ git stash show 0 --include-untracked --name-only | grep -E "2026-08-01" | wc -l
104
```

Donc :
- 104 chemins de fichiers 2026-08-01 sont dans le stash
- Incluant les runs 0700, 0752, 0800, 0815, 0900, 1000, 1100, 1200
- Le dossier 0815_release-freeze-integration a les 6 fichiers (01..07)
- Ils sont récupérables par `git stash pop` (mais cela mélangerait
  avec l'état actuel)
