# POC — Documentary skills DTP alignment

## Hypothesis

The four selected skills can consume C0-C5 observations and preserve their
previous read-only or non-destructive boundaries while routing documentary
findings through Critical Rule 16.

## Checks

- every selected skill names the C0-C5 validator and retains `UNKNOWN`;
- every selected skill requests `OUI`, `NON` or `PLUS_TARD`;
- the harmonizer no longer constructs a scalar current truth;
- the coherence auditor exposes identity, authority, relations, ontology,
  compatibility and confidence in findings;
- the gap integrator does not create a document or identity after detection;
- project context initialization negotiates the documentary contract without
  claiming conformity of existing artefacts;
- no selected skill references CC-11, CR-2, REVISE-C v3 or local ADR-0052;
- focused tests prove route proposals are not remediation.

## Success criteria

- all focused skill-alignment tests pass;
- all prior C0-C5 validation tests remain green;
- contract and convention lint remain non-blocking;
- only the four skills, tests and this run's evidence are changed.

## Stop criteria

Stop before any cleanup, skill execution against the whole repository, tag or
frontmatter write, migration, distribution change or workflow change.

## Decision

Décision: GO for the bounded skill-contract adaptation only. No real cleanup
run is opened by this POC.
