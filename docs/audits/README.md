# docs/audits/

Rapports d'audit horodatés produits par les skills vibebackbone.

Format : `{skill}-{YYYYMMDD-HHMM}.md`

Ces fichiers sont versionnés (contrairement à `SESSION.md`).

Les rapports supplantés ou non canoniques sont conservés dans `docs/archive/`
afin de préserver l'évidence sans les laisser comme audits actifs.
