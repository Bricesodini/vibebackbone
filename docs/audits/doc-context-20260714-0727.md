## Proposed canonical structure

- `docs/CONTEXT.md`: current objective and next action only.
- `docs/AUDIT_STATUS.md`: global verdict, one active-risk table, recent evidence
  pointers, and no copied measurements.
- `docs/INDEX.md`: navigation without manual catalog counts.
- `docs/runs/<id>/`: execution evidence.
- `docs/audits/`: immutable analyses and historical detail.
- `docs/archive/`: retired non-run documentation after explicit agreement.

No new documentation layer is proposed.

## Drift & contradictions

- `AUDIT_STATUS.md` mixed current risks with several generations of resolved
  findings and incompatible test/runtime counters.
- `INDEX.md` copied catalog counts that are already measurable from the index
  and filesystem.
- Five skill contracts used references one directory level too high; the Pi
  runtime profile used a repository-root path as though it were local.
- `docs/runs/routing-fix-verification.md` remains a loose historical artifact
  outside a timestamped run directory.
- Optional formatter/type-check baselines remain non-canonical and failing;
  this documentation-only pass does not widen into code cleanup.

## Compression plan

1. Keep one active risk table.
2. Replace old audit summaries with direct report/run links.
3. Remove copied test, prompt, skill, and runtime counters from active prose.
4. Keep resolved findings in their original reports and git history.
5. Repair only confirmed active local links.
6. Keep the navigation index role-based and short.
7. Leave long human guides unchanged unless a separate bounded audit proves
   duplication.
8. Re-run the link scan and generated dashboard after each status edit.

## Archive policy proposal

Do not auto-archive by age. Archive a non-run document only when it is
superseded, has a durable successor link, and a human approves the move.
Run directories, ADRs, audits, and the activity log remain immutable evidence.
The loose `docs/runs/routing-fix-verification.md` should be moved into a named
archive or reconstructed run only after explicit approval; it is not moved by
this pass.
