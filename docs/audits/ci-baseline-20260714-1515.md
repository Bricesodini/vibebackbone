# CI baseline audit — static-quality promotion

## Context

**Date**: 2026-07-14 15:15 Europe/Paris
**Mode**: DISTRIBUTION interpreted as DEV
**Provider**: GitHub Actions plus `scripts/vbb-ci-local.sh`
**Verdict**: `PARTIAL`

The workflow runs on every push and pull request across Ubuntu/macOS with
Python 3.11 and read-only repository permissions. The latest three remote runs
are green. Tests, credential scanning, contract lint, architecture lint and
runtime dry-run are present, but the now-clean static toolchain is absent.

## Actual CI behavior

- Remote: checkout with full history, Python 3.11, differential credentials
  gate, runtime dependencies, contract/architecture/runtime checks and pytest.
- Local: nine checks, including the same primary invariants plus loop closure,
  portability and project-init focused tests.
- Dependency install: remote installs `requirements.txt`; Ruff/mypy are pinned
  separately in `requirements-dev.txt` and therefore unavailable remotely.
- Permissions: `contents: read`; no write token or deployment permission.

## Findings

### CI-01 — Clean static invariants are not enforced

- **Severity**: P1
- **Finding**: Ruff check, Ruff format and mypy are clean but absent from both CI
  execution paths.
- **Evidence**: no canonical command appears in the workflow or local script.
- **Impact**: QOA-007 can regress immediately without failing a push/PR.
- **Recommended action**: add all three as blocking checks in local and remote
  CI, in the same order and with the same paths.

### CI-02 — Remote dependency installation omits supported dev tools

- **Severity**: P1
- **Finding**: GitHub installs only `requirements.txt`.
- **Evidence**: Ruff 0.13.1 and mypy 2.1.0 exist only in
  `requirements-dev.txt`.
- **Impact**: adding static commands without changing install would fail for
  missing executables rather than code quality.
- **Recommended action**: install `requirements-dev.txt` in GitHub Actions;
  it already includes runtime requirements transitively.

### CI-03 — Local prerequisite diagnostics omit Ruff/mypy

- **Severity**: P2
- **Finding**: `require_python_modules` checks only PyYAML and pytest.
- **Evidence**: Ruff and mypy are invoked as console commands but not detected.
- **Impact**: a contributor gets a generic failed check instead of one
  actionable dependency message.
- **Recommended action**: add `ruff` and `mypy` modules to the prerequisite map
  and point installation guidance to `requirements-dev.txt`.

### CI-04 — Gate wiring has no regression assertion

- **Severity**: P2
- **Finding**: architecture tests assert only that architecture lint is wired.
- **Evidence**: no test reads local/remote CI and requires all three canonical
  static commands or the dev manifest.
- **Impact**: a later workflow simplification could silently remove one side of
  local/remote parity.
- **Recommended action**: add textual wiring assertions for both CI surfaces and
  the remote development dependency install.

## Recommended corrective actions

1. Install `requirements-dev.txt` remotely.
2. Add blocking Ruff check, Ruff format check and mypy steps after dependency
   setup and before pytest in GitHub Actions.
3. Add the same three blocking `run_check` entries to local CI and update the
   prerequisite diagnostics.
4. Add regression assertions for command presence and parity.
5. Prove each command fails against a controlled temporary violation, restore
   the clean tree, then run P.R2 and observe both remote matrix jobs green.

No new workflow, permission, provider or build system is recommended.
