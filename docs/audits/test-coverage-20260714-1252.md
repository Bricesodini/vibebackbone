## Priority gaps

| Priority | Gap | Impact |
|---|---|---|
| P2 | Corrupt/unsupported manifest override path not directly tested | diagnostic or adoption regression |
| P2 | Retired bundle entry provenance preservation not directly tested | future bundle shrink could orphan metadata |
| P3 | Mid-copy filesystem failure is not fault-injected | rare partial copy after a successful logical preflight |

These gaps do not leave a P1 path uncovered. Conflict-driven partial copy — the
primary destructive risk — is directly tested.

## Top tests recommended next

1. Invalid JSON and unsupported schema must fail without `--overwrite-managed`.
2. The same invalid manifest must be replaceable only with both explicit hook
   and managed-asset permissions when hooks already exist.
3. A manifest entry retired from the current source list must retain provenance
   without deleting the consumer file.
4. If transactional filesystem guarantees are later required, inject a copy
   failure and assert rollback or a recoverable journal.

- Coverage percentage was intentionally not measured; critical behavior and
